# Student Marks Calculator in C

## About the Project
This is my beginner C programming project that calculates the total marks and percentage of three subjects.

## Features
- Takes marks for three subjects as input.
- Calculates total marks out of 300.
- Calculates the overall percentage.
- Displays the results.

## Technology Used
- C Programming Language

## Concepts Learned
- Variables and data types
- Input and output using scanf() and printf()
- Arithmetic operations
- Basic program structure in C

## Sample Output
```text
Enter marks for 3 subjects: 80 75 90
Total Marks = 245.00/300
Percentage = 81.67%
```
